# ADR-0012: Repositorio público, GNU AGPLv3 y protección de secretos

- **Fecha:** 2026-10-13
- **Estado:** Aceptado en diseño; implementación sujeta a verificación.

## Contexto
Los alumnos deben consultar y descargar el proyecto abiertamente; se pidió copyleft de red para software propio.

## Alternativas consideradas
Repositorio privado; licencias permisivas; AGPLv3 para código original; distribuir binarios sin fuente.

## Decisión
Repositorio público EnriqueMascote/HunterChain; licencia GNU AGPL-3.0-only para contenido original cuando corresponda. Las dependencias conservan sus propias licencias. No se subirán nombres de estudiantes, claves ni volúmenes de nodos.

## Consecuencias y riesgos
Las modificaciones de software cubierto por AGPL que se ofrezca por red pueden generar obligación de ofrecer su código correspondiente; habrá enlace 'Código fuente' en la GUI cuando opere. Publicar implica riesgo irreversible de fuga.

## Prueba de aceptación
Revisar licencia íntegra, referencias a fuente y .gitignore; escaneo de secretos antes de commit y auditoría de que no aparecen claves privadas.

## Reversibilidad y control documental
Cualquier modificación posterior exige ADR sucesor, impactos sobre manifiestos y, en red definitiva, ruta explícita de migración. Las pruebas y versiones se incorporarán al registro técnico.
