# ADR-0002: Un nodo por host físico mediante Docker

- **Fecha:** 2026-10-13
- **Estado:** Aceptado en diseño; ejecución sujeta a validación G0/G1.

## Contexto
Hay 25 personas con laptops propias Windows 11, Linux y macOS, >=8 GB RAM y >=4 cores, con admin local.

## Alternativas consideradas
VM por alumno; servidor central con 25 nodos; clientes nativos; contenedores Docker.

## Decisión
Cada alumno opera su propio Besu+Teku en Docker; validador opcional; 25 nodos físicos y no 25 procesos en el equipo docente.

## Consecuencias y riesgos
Demuestra P2P y fallas reales; requiere diseño multiplataforma, Docker Desktop/WSL2 y pruebas de memoria.

## Prueba de aceptación
Piloto en Windows 11 8 GB, Linux y macOS; medir p95 RAM y CPU sin swapping incapacitante, reinicios y persistencia.

## Reversibilidad
Cualquier cambio que afecte los parámetros del génesis exige un nuevo ADR, reconstrucción de devnet y, si la red definitiva ya fue lanzada, plan explícito de migración.
